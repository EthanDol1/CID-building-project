The diaries folder contains the diary data and the code necessary for obtaining the necessary quantities for the model from the diaries.

The building code folder contains the code for the three models: (1) full model, (2) equal probability model, (3) random topology model. There is code to generate and plot a single trajectory starting from any
space in the building. There is code to generate a number of trajectories and perform statistical analysis on those trajectories. This code can be used to generate usage and collisions statistics.

The survey analysis folder contains the code for analyzing the survey data.
